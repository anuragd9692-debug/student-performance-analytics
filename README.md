Student Performance Analytics System :-

Project Overview :

This is a Python mini project that analyzes student academic performance using Pandas and NumPy.

Objectives :

- Calculate total and average marks.
- Assign grades and determine pass/fail results.
- Analyze subject-wise performance.
- Identify top-performing students.
- Analyze attendance and class performance.

Technologies Used :

- Python
- Pandas
- NumPy
- Google Colab

Project Files :

- "main.py" — Main Python program.
- "Students.csv" — Student dataset.
- "Analysis_results.csv" — Analysis output.
- "Student_Performance_Analytics_System.ipynb" — Google Colab notebook.
- "Project_Documentation.txt" — Project documentation.

Conclusion :

This project demonstrates how Python, Pandas, and NumPy can be used to analyze student performance 
and generate useful academic insights.
